# Portafolio de Eduardo De Ávila

Portafolio estático de videojuegos, Unity/XR y desarrollo Full Stack. La web está en `cv/`.

## Vista previa

Servir `cv/` con un servidor HTTP estático y abrir `index.html`. No requiere instalación de paquetes ni compilación. Para hosting, configurar `cv` como directorio de publicación.

## Contenido

- Cube Colosseum y Lego Animals XR, ambos en desarrollo.
- Galería de imágenes de los materiales aportados por Eduardo.
- Especialidades, proyectos web, trayectoria y contacto.
- CV descargable en `cv/assets/Eduardo_De_Avila_CV_2026.pdf`.

Las imágenes originales proceden del flyer de Cube Colosseum y del documento Biodiversidad realidad virtual V8. Las copias web se optimizaron a WebP. Los modelos GLB anteriores se conservan como recursos; ya no se cargan en la portada. La web funciona sin JavaScript; el script solo mejora el menú móvil. Google Fonts es opcional y tiene fuentes de sistema como alternativa.

Mantener las capacidades implementadas separadas de futuras ampliaciones. No atribuir métricas de rendimiento o resultados educativos sin evidencia.
